# Applied Analytics Methods

An interactive web textbook covering generalized analytics methods for business, built as a companion to the Georgia Tech GTx DAB course on Generalized Analytics for Business (GAB).

## Live Site

[https://vkoul.github.io/Applied-Analytics/](https://vkoul.github.io/Applied-Analytics/)

## Topics Covered

| Chapter | Topic |
|---------|-------|
| 1 | Introduction to Analytics |
| 2 | Linear Models & OLS Regression |
| 3 | Binary Response Models (Logit, Probit) |
| 4 | Censored Data & Tobit Model |
| 5 | Count Data Models (Poisson, Negative Binomial) |
| 6 | Survival Analysis (Kaplan-Meier, Cox PH) |
| 7 | Discrete Choice Models (MNL, Nested Logit) |
| 8 | Instrumental Variables & 2SLS |
| 9 | Clustering Methods (K-Means, Hierarchical, DBSCAN) |
| 10 | Text Mining & NLP |
| 11 | Neural Networks |
| 12 | Deep Learning (CNN, RNN, LSTM) |

## Features

- **Interactive tooltips** with nested concept explanations (up to 4 levels deep)
- **90+ concept definitions** organized in a validated dependency graph
- **60 quiz questions** (5 per chapter) with instant feedback and score tracking
- **60 flashcards** with flip animation and mastery tracking
- **42 key formulas** rendered with KaTeX
- **8 real-world case studies** illustrating analytics concepts
- **Interactive concept map** showing prerequisites and dependencies
- **Dark mode** with system preference detection
- **Search** (Ctrl+K) across chapters, concepts, and formulas
- **Keyboard navigation** (arrow keys between chapters)
- **Reading progress** bar per chapter
- **Mobile responsive** layout

## Tech Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS
- React Router (HashRouter for GitHub Pages)
- KaTeX (math rendering)
- Recharts (interactive visualizations)
- Deployed via GitHub Actions to GitHub Pages

## Local Development

```bash
npm install --legacy-peer-deps
npm run dev
```
